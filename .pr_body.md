## Description

This PR implements Phase 4 of the SwarmMemory project: the FastMCP server. It exposes the core ingestion and retrieval functionality to LLM agents through standardized Model Context Protocol tools.

### Key Changes
- **MCP Server Initialization**: Created `swarm_memory/server/mcp.py` using `fastmcp` binding to the SSE transport layer.
- **Agent Tools Exposed**:
  - `memory_begin_run`: Initializes agent session metadata.
  - `memory_write`: Writes new facts/gotchas/insights with automatic LLM-based supersession.
  - `memory_search`: Hybrid RRF search with strict in-session deduplication using `SessionManager`.
  - `memory_invalidate`: Manually removes outdated facts.
  - `memory_end_run`: Concludes runs with structural fact extraction instructions.
  - `memory_list_runs`: For introspection.
- **Refactoring & Cleanup**:
  - Abstracted deduplication logic out of `FactReader` into `SessionManager`.
  - Consolidated fact supersession logic into a unified `invalidate_fact` method in `FactWriter`.
  - Removed obsolete deduplication tests and methods from `reader.py`.
- **Tool Docstrings Optimization**: Enhanced all tool docstrings according to best practices for agent comprehension (clear workflow boundaries, explicit parameter formats, and warnings for destructive actions).

### Testing
- **Integration Test (`test_mcp.py`)**: Added an end-to-end test simulating a full agent lifecycle (begin run, write fact, search fact, verify deduplication, invalidate fact).
- **SQLite-vec Constraints Fixed**: Resolved strict `LIMIT` vs `k=?` querying errors in hybrid searches that caused integration tests to fail.
- Verified test suite passes locally (`pytest tests/` - 88 passed).
- Verified `uvicorn` successfully boots the MCP SSE server locally.
